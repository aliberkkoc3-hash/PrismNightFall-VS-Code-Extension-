# 🌌 Prism Nightfall

**Prism Crew tarafından geliştirilen neon temalı, karanlık bir Visual Studio Code renk teması.**

Gece yarısı karanlığı, neon mor ve elektrik mavisi bir araya geldi. Sonuç: **Prism Nightfall.**

Kod yazarken gözünü alan bembeyaz ekranlardan sıkıldıysan doğru yerdesin. Burada her şey biraz daha karanlık, biraz daha renkli. Tabii bug'lar hâlâ kendi renginde geliyor, onları tema düzeltemiyor. :)

> **Prism Crew — Beyond The Spectrum.**

## ✨ Özellikler

- 🌑 **Gece Yarısı Arayüzü:** Mor tonlarla desteklenmiş koyu arka plan.
- 💜 **Neon Mor Vurgular:** Aktif sekmelerde ve arayüz öğelerinde belirgin mor tonlar.
- 🩵 **Elektrik Mavisi Ayrıntılar:** İmleç ve çeşitli arayüz vurguları için canlı camgöbeği.
- 🎨 **Renkli Sözdizimi:** Değişkenler, fonksiyonlar, anahtar kelimeler, dizeler ve sayılar için farklı renkler.
- 🖥️ **Uyumlu Terminal:** Terminal renkleri de temanın genel görünümüyle uyumludur.
- ⚡ **Hafif Tasarım:** Tema, renk ve görünüm özelleştirmesi içindir; ayrı bir arka plan sunucusuna ihtiyaç duymaz.

## 💻 Dil Desteği

Prism Nightfall, VS Code'un ve ilgili dil eklentilerinin sağladığı sözdizimi renklendirmesinden yararlanır.

Aşağıdaki dillerde kullanılabilir:

- JavaScript ve TypeScript
- HTML ve CSS
- Java
- Lua
- Haxe
- JSON
- Python

**Not:** Her dildeki bütün öğelerin aynı renklerle görünmesi garanti değildir. Kurulu dil eklentileri ve anlamsal renklendirme ayarları sonucu etkileyebilir.

## 🚀 Geliştirme Sürümünü Test Etme

Henüz pakete dönüştürmeden temayı geliştirme ortamında deneyebilirsin.

1. Proje klasörünü VS Code'da aç.
2. **Run and Debug** paneline gir.
3. `Run Prism Nightfall Extension` yapılandırmasını seç.
4. `F5` tuşuna bas.
5. Açılan geliştirme penceresinde `Ctrl + K`, ardından `Ctrl + T` tuşlarına bas.
6. Listeden **Prism Nightfall** temasını seç.

Bu yöntem, temayı ayrı bir geliştirme penceresinde denemeni sağlar.

## 🛠️ Temayı Özelleştirme

Tema dosyası:

`themes/prism-nightfall-color-theme.json`

- `colors`: Editör ve arayüz renklerini belirler.
- `tokenColors`: Kod içindeki sözdizimi renklerini belirler.

Bir rengi beğenmedin mi? Değiştir. Moru fazla mı kaçırdık? Biraz kıs. Kodun kendisi kırmızı hata veriyorsa onu da ayrıca düzeltmek gerekiyor. :)
